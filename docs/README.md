# OctoAcme Project Management Docs

This repository centralizes the core project management processes used by OctoAcme.

## Project management process summary
OctoAcme follows a simple lifecycle:
- Initiation: validate the problem, stakeholders, and success criteria.
- Planning: define scope, backlog, milestones, risks, and dependencies.
- Execution: run delivery in small increments with standups, reviews, and tracking.
- Release: validate readiness, deploy safely, and communicate outcomes.
- Close & improvement: capture learnings and drive continuous improvement.
